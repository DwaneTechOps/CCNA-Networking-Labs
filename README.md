# CCNA Networking & Network Security Labs

## Overview

This repository documents my hands-on networking and network security projects using Cisco Packet Tracer.

The labs focus on developing practical skills in network configuration, troubleshooting, routing, switching, and network security.

Each project includes a network scenario, configuration details, testing results, and a downloadable Packet Tracer file.

## Technologies & Skills

- Cisco Packet Tracer
- Cisco IOS
- Routing and switching
- VLANs and inter-VLAN routing
- Access Control Lists (ACLs)
- IP addressing and subnetting
- Network troubleshooting
- Network security

## Projects

### Lab 05 — Extended ACL Network Security

**Scenario:** Skyfall Technologies requires network security controls to restrict communication between departments while maintaining authorized network access.

**Skills demonstrated:**
- Configuring named extended ACLs
- Applying ACLs to router subinterfaces
- Controlling inter-VLAN traffic
- Verifying ACL rules and match counters
- Troubleshooting network connectivity
